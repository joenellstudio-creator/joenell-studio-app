Joe Photo Studio portable mode

While this file sits next to photocraft.exe, Joe Photo Studio keeps its preferences, brush presets,
crash-recovery autosaves and startup state in the PhotoCraftData folder beside it, and writes
nothing to %APPDATA% or %LOCALAPPDATA%. Copy the whole folder to move Joe Photo Studio with its settings.

Delete this file to use the normal per-user folders instead: %APPDATA%\Photocraft for settings
and %LOCALAPPDATA%\Photocraft\Recovery for crash-recovery autosaves. If PhotoCraftData can't be
written (for example on a read-only drive), Joe Photo Studio says so and uses those folders instead.
